NOVA VERSÃO
────────────────────────────────────────────────────────────
A versão 1.6.0 inicia uma nova fase de organização,
configuração e comunicação do Quaq.

[ CONFIGURAÇÃO ]
────────────────────────────────────────────────────────────

Novo sistema de configuração do Quaq

Novo comando: quaq config <opção>

Opções:
• nome
• email
• senha

Exemplos:

  quaq config nome
  quaq config nome --def "Henrique"

  quaq config email
  quaq config email --def "exemplo@email.com"

  quaq config senha
  quaq config senha --def "senha"
Configurações armazenadas em config.json
Informações sensíveis armazenadas no cofre de credenciais

[ EMAIL ]
────────────────────────────────────────────────────────────

Email agora é obtido através do config.json
Removida dependência do .env para o email
Senha agora é obtida através do cofre de credenciais
Removida dependência do .env para a senha

[ LOGS ]
────────────────────────────────────────────────────────────

Novo sistema de logs

Novo comando:

quaq logs

Permite visualizar os registros gerados pelo Quaq

[ FUSO HORARIO ]
────────────────────────────────────────────────────────────

Novo conversor de fuso horário

Novo comando:

quaq hora <origem> <destino> <hora>

Exemplo:

  quaq hora brasil vietna 13:20
Conversao de horarios entre diferentes fusos

[ REMOCOES ]
────────────────────────────────────────────────────────────

[ ALTERAÇÕES ]
────────────────────────────────────────────────────────────

novoService

Simplificação das funções de criação de projetos.
As funções foram unificadas em uma única função, permitindo
criar diferentes tipos de projeto apenas alterando os argumentos.

motivacaoService

Unificação dos serviços Advice e Motivação em um único serviço:
motivacaoService.

O comando "adv" foi renomeado para "conselho".

Novo layout

Padronização da interface do terminal.

Os Console.WriteLine utilizados pelos comandos foram substituídos
pelo UiService, centralizando a apresentação das informações e
mantendo um padrão visual único no Quaq.

Foram adicionadas as seguintes funções:

LinhaUi(titulo, texto)
LinhaUi(texto)
AvisoUi(texto)
ErroUi(texto)
ListaUi(titulo, linhas)

O UiService permite criar caixas de informação, avisos, erros e
listas com largura ajustada automaticamente de acordo com o conteúdo.

[ COMANDOS ]
────────────────────────────────────────────────────────────

Comando renomeado:

quaq conselho

Substitui o antigo comando:

quaq adv
