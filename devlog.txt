NOVA VERSÃO
────────────────────────────────────────────────────────────
A versão 1.6.0 inicia uma nova fase de organização,
configuração e comunicação do Quaq.

[ CONFIGURAÇÃO ]
────────────────────────────────────────────────────────────

Novo sistema de configuração do Quaq

Novo comando: quaq config <opção>

Opções:
• nome
• email
• senha

Exemplos:

  quaq config nome
  quaq config nome --def "Henrique"

  quaq config email
  quaq config email --def "exemplo@email.com"

  quaq config senha
  quaq config senha --def "senha"
Configurações armazenadas em config.json
Informações sensíveis armazenadas no cofre de credenciais

[ EMAIL ]
────────────────────────────────────────────────────────────

Email agora é obtido através do config.json
Removida dependência do .env para o email
Senha agora é obtida através do cofre de credenciais
Removida dependência do .env para a senha

[ LOGS ]
────────────────────────────────────────────────────────────

Novo sistema de logs

Novo comando:

quaq logs

Permite visualizar os registros gerados pelo Quaq

[ FUSO HORARIO ]
────────────────────────────────────────────────────────────

Novo conversor de fuso horário

Novo comando:

quaq hora <origem> <destino> <hora>

Exemplo:

  quaq hora brasil vietna 13:20
Conversao de horarios entre diferentes fusos

[ REMOCOES ]
────────────────────────────────────────────────────────────

Removida a funcao "fala" da tela inicial

[ RESUMO ]
────────────────────────────────────────────────────────────

Quaq 1.6.0

Configuracao
Cofre de credenciais
Logs
Conversor de fuso horario
Funcao fala da tela inicial

[ ALTERAÇÕES ]
────────────────────────────────────────────────────────────

novoService

Simplificação das funções de criação de projetos.
As funções foram unificadas em uma única função, permitindo
criar diferentes tipos de projeto apenas alterando os argumentos.

motivacaoService

Unificação dos serviços Advice e Motivação em um único serviço:
motivacaoService.

O comando "adv" foi renomeado para "conselho".

Novo layout

Padronização da interface do terminal.

Os Console.WriteLine utilizados pelos comandos foram substituídos
pelo UiService, centralizando a apresentação das informações e
mantendo um padrão visual único no Quaq.

Foram adicionadas as seguintes funções:

LinhaUi(titulo, texto)
LinhaUi(texto)
AvisoUi(texto)
ErroUi(texto)
ListaUi(titulo, linhas)

O UiService permite criar caixas de informação, avisos, erros e
listas com largura ajustada automaticamente de acordo com o conteúdo.

[ COMANDOS ]
────────────────────────────────────────────────────────────

Comando renomeado:

quaq conselho

Substitui o antigo comando:

quaq adv

[ RESUMO ]
────────────────────────────────────────────────────────────

Quaq 1.6.1

Unificação e simplificação da criação de projetos.
Unificação dos serviços de Advice e Motivação.
Padronização da interface do terminal.
Criação do UiService para centralizar a interface.
Renomeação do comando "adv" para "conselho".

╔══════════════════════════════════════════════════════════════╗
║                     QUAQ 1.6.3 — DEV LOG                    ║
╚══════════════════════════════════════════════════════════════╝

[ NOVIDADES ]
────────────────────────────────────────────────────────────

* Expansão do sistema de criação de projetos.

  Agora o comando "novo" permite criar projetos Python e Rust,
  além dos projetos .NET já existentes.

* O suporte foi integrado às categorias de projetos pessoais
  e de testes.

  Exemplos:

  quaq novo pessoal ProjetoPython -py

  quaq novo pessoal ProjetoRust -rust

  quaq novo teste TestePython -py

  quaq novo teste TesteRust -rust

* O comando "quaq rodar" foi ampliado para executar diferentes
  tipos de projetos e programas.

  Tecnologias suportadas:

  * .NET
  * Python
  * Rust
  * React

* "quaq rodar" agora aceita argumentos destinados ao programa
  executado através de "--".

  Exemplo:

  quaq rodar -- arg1 arg2

[ ALTERAÇÕES ]
────────────────────────────────────────────────────────────

* A calculadora passou a aceitar expressões com espaços.

  Exemplo:

  1 + 1

  Antes, a entrada precisava seguir a formatação sem espaços.
  Agora, expressões matemáticas com espaços podem ser processadas.

* O UiService foi atualizado para utilizar o Spectre.Console.

  A mudança melhora a base da interface do Quaq e permite utilizar
  os recursos de renderização e interação fornecidos pela biblioteca.

[ MELHORIAS ]
────────────────────────────────────────────────────────────

* Adicionado o método:

  OkUi("texto")

  O método passa a fazer parte do UiService para exibição de
  mensagens de confirmação ou sucesso.

* O sistema de execução do Quaq ficou mais abrangente, permitindo
  utilizar o mesmo comando para diferentes tecnologias.

[ ESTRUTURA INTERNA ]
────────────────────────────────────────────────────────────

* Criado o DependenciaService.

* O serviço ainda não possui implementação funcional nesta versão,
  servindo como estrutura inicial para futuras funcionalidades.

[ COMANDOS ]
────────────────────────────────────────────────────────────

* Criação de projeto pessoal:

  quaq novo pessoal <Nome>

* Criação de Web API pessoal:

  quaq novo pessoal <Nome> -api

* Criação de projeto Python pessoal:

  quaq novo pessoal <Nome> -py

* Criação de projeto Rust pessoal:

  quaq novo pessoal <Nome> -rust

* Criação de projeto de teste:

  quaq novo teste <Nome>

* Criação de Web API de teste:

  quaq novo teste <Nome> -api

* Criação de projeto Python de teste:

  quaq novo teste <Nome> -py

* Criação de projeto Rust de teste:

  quaq novo teste <Nome> -rust

* Execução de programas com argumentos:

  quaq rodar -- arg1 arg2

[ RESUMO ]
────────────────────────────────────────────────────────────

Quaq 1.6.3

* Expansão da criação de projetos para Python e Rust.
* Suporte a projetos pessoais e de testes.
* "quaq rodar" agora suporta .NET, Python, Rust e React.
* Adicionado suporte a argumentos através de "--".
* Calculadora agora aceita expressões com espaços.
* UiService atualizado para utilizar Spectre.Console.
* Adicionado OkUi("texto").
* Criado DependenciaService como estrutura inicial.

[ NOVIDADES ]
────────────────────────────────────────────────────────────

Adicionados novos subcomandos de menu para facilitar a navegação
e a seleção de opções dentro do Quaq.

Adicionado o comando:

quaq proj menu

Centraliza as opções relacionadas a projetos em um menu de seleção.

Adicionado o comando:

quaq proj anotacao menu

Permite acessar as opções de anotações por meio de um menu.

Adicionado o comando:

quaq proj abrir menu

Permite acessar as opções para abrir projetos por meio de um menu.

Adicionado o comando:

quaq dado rolar menu

Nova função para rolagem de dados. Utiliza uma quantidade fixa de
faces, executa múltiplas rolagens e exibe os resultados individuais
juntamente com o total.

[ ALTERAÇÕES ]
────────────────────────────────────────────────────────────

O comando de anotações foi alterado:

quaq proj anotacao lista

passou a utilizar:

quaq proj anotacao menu

O comando para abrir projetos foi alterado:

quaq proj abrir todos

passou a utilizar:

quaq proj abrir menu

O comando de dados foi reorganizado:

quaq dado x

passou a utilizar:

quaq dado rolar x

Também foi adicionado:

quaq dado rolar menu

O comando "novo" foi modificado. Anteriormente, os argumentos eram
informados diretamente:

quaq novo <argumentos>

Agora o comando abre um menu de seleção:

quaq novo

[ MELHORIAS ]
────────────────────────────────────────────────────────────

Todos os comandos que utilizam menus passaram a utilizar a função
de seleção do Spectre.Console, facilitando a escolha das opções
diretamente pelo terminal.
O sistema de diretórios foi reorganizado para melhorar a estrutura
dos arquivos do Quaq e dos projetos.

O diretório:

repos

passou a utilizar:

source/repos

O diretório de dados do Quaq:

username/.quaq

passou a utilizar:

.config/quaq

O sistema agora possui diretórios dinâmicos, permitindo escolher
onde os repositórios de projetos serão armazenados e criar novos
diretórios para projetos.

[ CORREÇÕES ]
────────────────────────────────────────────────────────────

Corrigido um bug no funcionamento do Pomodoro.

Nova forma de rolagem de dados:

[ ALTERAÇÕES ]
────────────────────────────────────────────────────────────

O comando anotacao passou a utilizar menus para seleção
e gerenciamento de anotações.
Os subcomandos de anotacao foram reorganizados:
menu e anotar foram substituídos por deletar e menu.
O comando baixarmp3 foi renomeado para ymp3.
O comando ymp3 deixou de receber o nome da playlist como
argumento. A playlist agora é selecionada por meio de menu.
O comando codar não precisa mais receber o nome do projeto
como argumento. O projeto agora é selecionado por menu.
O comando contato passou a utilizar menus para definir
informações de contato.
Os subcomandos email e telefone do comando contato foram
substituídos por definir.
O comando contato agora recebe apenas o nome do projeto
como argumento. Dentro do comando, um menu permite escolher
entre definir email ou telefone.
O subcomando deletar do comando contato não precisa mais
receber o nome do contato como argumento. O contato agora
é selecionado por menu.
O comando playlist não precisa mais receber o nome da
playlist como argumento.
A opção de shuffle do comando playlist passou a ser
selecionada por menu.
O comando proj perdeu o subcomando menu.
Os subcomandos do comando proj que utilizam nome passaram
a utilizar menus para selecionar os itens, com exceção
do comando salvar.
O comando tarefa foi renomeado para tarefas.

[ MELHORIAS ]
────────────────────────────────────────────────────────────

Maior utilização de menus interativos nos comandos do Quaq.
Redução da quantidade de argumentos necessários para executar
comandos.
Seleção de itens diretamente pelos menus, tornando a utilização
dos comandos mais simples e interativa.

A calculadora agora permite inserir expressões matemáticas
diretamente, como:

quaq calcular

Exemplo:
2 * 2

O comando calcular passou a coletar a expressão matemática
dentro do próprio comando.

[ CORREÇÕES ]
────────────────────────────────────────────────────────────

Correção de um bug na calculadora.

Correção do fluxo de entrada de expressões matemáticas,
permitindo operações como:

2 * 2
